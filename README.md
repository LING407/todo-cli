# todo-cli
Todo CLI 是一个简洁高效的终端待办事项管理工具，专为喜欢在命令行中工作的开发者设计。  核心功能： • 添加、删除、完成/取消完成待办事项 • 三级优先级标记（高/中/低） • 任务描述与备注 • JSON 文件持久化，数据自动保存 • 一键清除所有已完成事项  技术特点： • 零运行时依赖，仅使用 Python 标准库 • 清晰的分层架构（模型 / 存储 / 命令行接口） • 完整的单元测试覆盖（34 个测试用例） • 支持 pip install 安装，提供 todo 命令全局调用 • 兼容 Python 3.8+  适合场景：日常任务管理、开发待办跟踪、快速记录灵感。
